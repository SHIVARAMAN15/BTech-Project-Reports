# 🎓 B.Tech Project Reports & Documentation

A collection of project reports, technical documentation, source code, and supporting materials developed during my **B.Tech in Electronics and Communication Engineering (AI & Cybernetics)**.

This repository brings together my academic projects and technical project work involving **Embedded Systems, IoT, Digital Signal Processing, Robotics, Automation, Artificial Intelligence, and Hardware Development**.

---

## 📚 Projects

### 🌱 1. Smart Aeroponics System

An IoT-based automated aeroponics system designed for soil-less plant cultivation using real-time sensor monitoring, ESP32-based control, automated nutrient dosing, ultrasonic mist generation, wireless telemetry, and AI-assisted data analysis.

**Key Technologies:**

- ESP32
- Embedded C
- IoT
- pH Sensor
- TDS / EC Sensor
- DS18B20
- Water-Level Sensor
- Automated Nutrient Dosing
- Ultrasonic Nebulizer
- Wi-Fi
- Telegram Bot
- Streamlit
- Local AI / ML

### ❤️ 4. ECG Signal Processing and Heart Rate Analysis

A Python-based digital signal processing project focused on ECG waveform preprocessing, noise reduction, Butterworth filtering, FFT-based frequency-domain analysis, R-peak detection, feature extraction, and heart-rate estimation.

The project uses ECG data from the **MIT-BIH Arrhythmia Database** and demonstrates practical biomedical signal-processing techniques.

**Key Technologies:**

- Python
- NumPy
- Pandas
- SciPy
- Matplotlib
- NeuroKit2
- WFDB
- Butterworth Filtering
- FFT
- R-Peak Detection
- Heart-Rate Estimation
- Digital Signal Processing

**Project Repository:**

[View ECG Signal Processing Project](./ECG-Signal-Processing-and-Heart-Rate-Analysis)
